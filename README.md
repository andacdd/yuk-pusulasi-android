# Yük Pusulası — Android

Yük sahipleri ve araç sahipleri için ilan uygulaması. Bu depo yalnızca Android kurulum dosyalarını (APK) dağıtır.

## Kurulum

1. [En son sürümü indirin](https://github.com/andacdd/yuk-pusulasi-android/releases/latest) (`yuk-pusulasi-x.y.z.apk`).
2. Telefonunuzda açın. Android "bilinmeyen kaynaklardan yükleme" izni isterse bu kez için izin verin.
3. Uygulamayı açın.

Yeni sürüm çıktığında uygulama sizi bu sayfaya yönlendirir.

Gizlilik politikası: https://yukpusulasi.vercel.app/gizlilik
